# Fitzo 1.5.0 replacement — nutrition dates and OTA support

The owner requested the latest backend changes live with a replacement store
build and review submission. The owner also explicitly approved OTA support in
the related nutrition-fix chat. Source starts at `81f5c29` on
`codex/release-1.5.0`.

## Changes

- Meals and nutrition totals follow each member's named timezone. New meals
  retain their original local date during travel. Legacy India-assigned dates
  are interpreted using the member timezone without rewriting meal records.
- The mobile client sends `X-Fitzo-Timezone`, refreshes at local midnight and
  foregrounding, and discards stale prior-day results.
- `expo-updates` is included with the existing EAS project URL, fingerprint
  runtime compatibility, and separate development, preview and production
  channels. Users first need this native store build to receive future compatible
  JavaScript/asset updates. Native changes still need a new binary.
- Duplicate generated permission, background-mode and intent-filter entries were
  removed from the saved app configuration. Existing application identifiers and
  widget provisioning declarations are retained.
