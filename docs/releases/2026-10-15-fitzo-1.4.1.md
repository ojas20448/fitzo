# Fitzo 1.4.1 — workout photo cards

Release source: `codex/release-1.4.1-photo-cards`, based on published 1.4.0 commit `13da460`. Only the photo share composer, related card styles, tests, and release configuration are included.

## What's new

Pinch, drag, and rotate your workout card while your photo stays fixed. New size and reset controls make positioning easier. Photo cards have improved contrast, and compact controls leave more room for the preview on small screens.

## Validation

- Isolated release checkout: 45 suites / 349 mobile tests passed; TypeScript passed.
- Changed feature files passed lint. Production Android JavaScript bundle compiled during feature verification.
- All five styles were visually reviewed with long names, twelve exercises, and eight personal records.
- Camera permission, data handling, native dependencies, signing identifiers, supported devices, and production API endpoint are unchanged.
- Physical-device multitouch and the native share sheet have not been smoke-tested in this session.

## Distribution

Version 1.4.1; EAS production builds increment the existing Android 27 / iOS 24 build numbers. Google Play production submission is configured for a 1% staged rollout. App Store phased release will be set when the new version is prepared in App Store Connect.

Halt the rollout for a reported blocking camera/share regression, a crash-free rate below 99.5%, or a sustained crash/ANR increase. Fix forward with a higher build number; do not reuse a rejected or previously uploaded build number.
