# Review fixes — 20 September 2026

Implemented locally in Fitzo and the sibling Fitzo website repository. These changes have not been committed, deployed, or submitted to either store in this task.

## Fixed

- Share composer: moved its context hook before early returns, normalized live gesture offsets so preview and export use the same coordinate system, committed cancelled gestures consistently, and captured the latest shared-value placement.
- Nutrition: after research and final owner preferences, automatic protein is 1.8 g/kg for maintenance and muscle gain, and 2.0 for fat loss, independent of calories. Suggested fat is about 30%, with carbs filling the rest. Explicit personal protein/fat can be retained when editing the fitness profile. Invalid, contradictory and zero-calorie macro overrides are rejected after final calculation. Formula version is now 4. See `2026-09-20-nutrition-policy.md` for evidence and examples.
- Attendance: both workout completion paths close existing gym visits. Synthetic training attendance uses no gym; a later QR check-in upgrades it without awarding another attendance bonus. A conflicting QR check-in no longer reports false success.
- Buddy privacy: completed structured sessions and last-workout metadata respect sharing permissions. Private workout completion no longer sends friend notifications.
- Invitations: correct API status handling for existing friends, incoming/outgoing requests and blocks; retry on status errors; validated invites persist through login/onboarding with a 24-hour expiry. QR scans use this same flow. Malformed/non-Fitzo QR links are rejected.
- Website: fixed the production-build lint failure, added the verified Fitzo App Store destination, and added an invalid-invite state and instructions for returning after installation.
- Link configuration: added the Apple association document and native associated-domain setting for the canonical www domain. Added an Android association endpoint that requires the real Play App Signing SHA-256 certificate fingerprint.
